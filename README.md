# Flow

Browser / Chrome extension that uses face detection + ML models to analyze how focused you are while studying.

## What it does
- Watches your webcam in the browser
- Detects your face + tracks attention indicators
- Determines focus state in real time

## Stack
- TensorFlow.js (face-api.min.js, coco-ssd.min.js)
- Vanilla JS browser extension (manifest.json, popup, content scripts, panel)

## Status
Prototype — abandoned but functional.
